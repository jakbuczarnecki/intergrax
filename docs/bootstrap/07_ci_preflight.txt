What GitHub actually runs
- Pull request, push to main → job ci-smoke only (blocks PR / push; must be green).
- Nightly schedule (03:00 UTC), workflow_dispatch profile full → gate-tests, gate-governance-tier, gate-governance-wiring, gate-closeout (runs after merge; does not block PR).

To avoid green PR then red nightly, run both profiles locally before merge to main.

Required local run (single command — preferred)
From repository root:
uv run python scripts/ci/run_regression_gate_ci.py --profile all

This executes in order:
1. ci-smoke — exact PR / push parity
2. gate-tests — full unit gate
3. gate-governance-tier — tier / registry governance scripts
4. gate-governance-wiring — harness wiring + intergrax doctor --ci
5. gate-closeout — architecture closeout + export scripts

Success criteria: script exit code 0 and every job line in the summary shows PASS.

Faster option (PR / push only — only if operator explicitly asks for smoke):
uv run python scripts/ci/run_regression_gate_ci.py --profile smoke

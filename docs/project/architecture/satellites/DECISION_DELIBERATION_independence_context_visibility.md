# DECISION_DELIBERATION — independence and context visibility

**Parent hub:** [`DECISION_DELIBERATION.md`](../DECISION_DELIBERATION.md)

## Roles

Configured participant roles (e.g. proposer, skeptic, synthesizer) with explicit contracts.

## Context visibility

Per-role visibility policy controls tool, evidence, and context exposure — no hidden shared CoT store.

## Provider / model independence

Meaningful separation between participant models or explicit non-independent declaration.

## Tool / evidence visibility

Evidence and tool results are attributed per participant for audit reconstruction.

## No hidden CoT persistence

Private chain-of-thought is not persisted as authoritative evidence.

## How to read this register

- **Rendering.** Decisions made in the Operator's chat were given in Polish. The `Decision` column holds a **labelled English rendering**, not a verbatim quote. Where the Operator's words are known to be short, the table says so.
- **Records.** Paths of the form `.tmp/session/...` are **untracked session records** of the orchestrating session. They are cited as the source of the rendering; they are not repository evidence. The program plan that cites these decisions is published at [`arch_freeze_program/MEP-AF2_v2.1.md`](./arch_freeze_program/MEP-AF2_v2.1.md) (sections 0, C, M, Appendix Z); see [`arch_freeze_program/README.md`](./arch_freeze_program/README.md).
- **Status vocabulary.** `DECIDED` = the Operator accepted the option (record only). `COMPLETE` / `EXECUTED` = the action is done and recorded elsewhere. `SUPERSEDED` = replaced by a later authority; the original row is kept. `COMPENSATING` = satisfied through a compensating control, not the original action. `OPEN` = no decision yet. Nothing here is a PASS, closure or independent verification.
- **Row history.** The eight original rows (OD-IC-01 .. OD-ARCH-FREEZE-01) are kept. Their previous status is shown in the `Status` cell after `was`. The original columns PURPOSE / PREREQUISITES / EVIDENCE / ROLE / SIGNATURE / TIMING / CONSEQUENCE are folded into `Question` and `Authority / record`.
- **Record published by PR #615.** Rows OD-REM-01..08, C1–C10 and DS-1..DS-6 (DP-01..DP-68) are one-line pointers to the Operator decision record `docs/project/maintainers/qualification/eqo_a_remediation/OPERATOR_DECISIONS_EQOA_REMEDIATION.md@743087d57`, merged via #615 (companions `OPERATOR_ANSWERS_CODE_WAVE_TRANSCRIPTION.md` and `README.md` in the same folder).
- **Signing.** No agent signs any decision (plan section M). Rows marked `OPEN` stay with the Operator or a recorded delegate.

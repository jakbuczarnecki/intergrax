- **Redactions (machine-specific paths).** One local worktree path in the plan copy (section I, the shared test lock) and one truncated local path in `WP12_AUTHORIZATION_REQUESTS.md` (AB-12) were replaced by `<worktree base>` and `<local path>`. A scan for tokens, e-mail addresses, user-profile paths and credentials found nothing else. Because of the redactions and the line-ending change, the digests in `SOURCES.sha256` for the copies differ from the digests of the sources; both are listed.
- **Pinning.** The plan cites only this folder path and the publishing commit SHA, never its own digest; the digest lives in `SOURCES.sha256`.
- **Superseded content.** Plan text that names session artefacts under `.tmp/` refers to untracked files of the orchestrating session; they are not repository evidence.

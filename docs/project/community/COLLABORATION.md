## Evaluation feedback

Public access does not authorize running the software. Send a reproducible report only when a separate written authorization, a prior license covering that copy, or applicable law already allows that run. This page is not that authorization. Where a report is allowed, include:

- pinned revision;
- evaluation target and canonical path;
- environment;
- expected result and observed result;
- evidence;
- skipped or unavailable steps;
- friction or blocker;
- known limitation.

Do not reproduce the complete evaluation template here. Concrete evidence helps reviewers act on a bounded result without expanding permission boundaries.

## Feedback and contributions are different

Issue comments, suggestions, bug reports, and observations do not transfer copyright and do not license protected Intergrax materials. Material offered for inclusion does not, by that offer alone, give the maintainer rights in the contribution or give the sender rights in the existing materials. Those rights require a separate written agreement.

Follow [CONTRIBUTING.md](../../../CONTRIBUTING.md) before offering documentation or code. Prior discussion is recommended for substantial work. Discussion and submission do not grant permission to run or modify the software, and submission does not guarantee acceptance. Merging code does not transfer copyright.

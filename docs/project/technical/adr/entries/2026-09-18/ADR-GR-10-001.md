## Context

GR-10-R2 wired PRE_MODEL evaluation immediately before structured INFERENCE provider invocation. Independent audit of commit `0ba1a514c60af1c319bd35fc714268de9640bcbd` confirmed **placement** (before provider I/O) but identified two architectural blockers:

1. `CanonicalExecutionIntakeRequest` gained required `workspace_id` / `principal_id` without a formal intake-boundary decision.
2. INFERENCE PRE_MODEL calls `evaluate_pre_llm` with `agent_id=""`, while the public PRE_MODEL contract names `agent_id` explicitly and existing agentic paths supply real agent roster identifiers.

Runtime remediation may pass tests while **identity semantics and contract boundaries remain unresolved**. This ADR freezes platform semantics before GR-10-R2-R1 (wiring) or GR-10-R2-C1 (contract revision).

Platform invariant (unchanged): **Governance** answers permission; **Execution** owns lifecycle and canonical execution identity; **Evidence** records facts and is not an identity authority.

## Problem

### A. What is the canonical actor for PRE_MODEL on non-agentic INFERENCE?

PRE_MODEL must evaluate permission for a **governance actor** (who is acting under which tenant/workspace scope) before model invocation. The current `evaluate_pre_llm(tenant_id, agent_id, …)` surface does not carry `principal_id`, forcing call sites to pass an empty `agent_id` on INFERENCE.

### B. Should `CanonicalExecutionIntakeRequest` carry `workspace_id` and `principal_id`?

GR-2 MODEL C1 introduced a public intake boundary after root admission. Fields were added as required without documenting ownership, source of truth, or duplicate-truth rules relative to `RootExecutionLaunchRequest` and active execution carriers.

### C. Single governance identity source for live PRE_MODEL

Current INFERENCE wiring resolves `tenant_id` via active governance identity, then lineage, then failure evidence context. Evidence and diagnostics must not become principal authority.

## Current mismatch

| Area | Observed behavior | Architectural issue |
|------|-------------------|----------------------|
| PRE_MODEL contract | `PolicyEngine.evaluate_pre_llm(..., agent_id: str, …)` | No `principal_id`; `agent_id` name implies agent roster identity |
| INFERENCE PRE_MODEL | `agent_id=""` in `enforce_pre_model_before_structured_inference` | Empty string is not defined as canonical “no agent” semantics |
| ORCHESTRATION planning | `task.agent_id or ""` in `PlanningRunner` | Legacy empty fallback ≠ approved identity |
| Intake contract | Required `tenant_id`, `workspace_id`, `principal_id` on `CanonicalExecutionIntakeRequest` | Breaking public shape without ADR; duplicate with launch request |
| Tenant resolution | Fallback to lineage / failure evidence for `tenant_id` only | Evidence must not author principal; lineage is not principal authority |
| G3B matrix | PRE_MODEL **COVERED** for ORCHESTRATION/AGENTIC only | INFERENCE adoption **BLOCKED** until identity-compliant wiring |

## Identity ownership

| Concept | Owner plane | Meaning |
|---------|-------------|---------|
| **principal_id** | Governance / collaborative-work authority | Human or service principal whose permission is evaluated |
| **agent_id** (platform roster) | Agent distribution / UAEP materialization | Which agent **definition** executes a step — not interchangeable with principal |
| **tenant_id / workspace_id** | Governance scope | Isolation and policy scope for evaluation |
| **task_id / run_id / attempt_id / execution_id** | Execution | Canonical execution correlation (GR-1); not governance actors |

PRE_MODEL **permission subject** (who): **`principal_id`** from trusted admission material, bound for the live execution scope.

PRE_MODEL **agent binding** (which agent definition, when applicable): **`agent_id`** only for agent-step model policy (`PreModelPhase.AGENT_STEP`) when an agent roster identity is materialized.

## PRE_MODEL subject semantics

### Decision: governance actor = `principal_id`; agent roster = optional `agent_id`

- **Canonical PRE_MODEL governance subject:** non-empty `principal_id` scoped with `tenant_id` and `workspace_id`.
- **`agent_id` parameter (current contract name):** semantically **agent roster / agent definition identifier** for agent-step rules and audit — **not** a generic platform subject identifier and **not** a substitute for `principal_id`.
- **Empty `agent_id`:** **not approved** as canonical semantics (including INFERENCE). Interim runtime uses `agent_id=""` as an unapproved workaround; GR-10-R2 remains **BLOCKED** until contract + wiring remediation.
- **Fake sentinel values** (`"inference"`, `"default"`, `"unknown"`): **rejected** as identity workarounds.

### Strategy subject matrix

| Strategy | PRE_MODEL caller (production-class) | principal | agent (roster) | Canonical PRE_MODEL subject | Rule |
|----------|-------------------------------------|-----------|----------------|----------------------------|------|
| **INFERENCE** | `enforce_pre_model_before_structured_inference` | From `ActiveExecutionGovernanceIdentity` (required for evidence) | None | **`principal_id`** (+ tenant/workspace) | No agent roster on path; must not use empty/fake `agent_id` after remediation |
| **AGENTIC** | `PolicyEnforcingLLMRouter` / `StepKernel` | From active governance identity (must match admission) | `kernel_ctx.agent_id` / router-bound agent | **`principal_id`** for permission; **`agent_id`** for agent-step model deny lists | Both dimensions when `PreModelPhase.AGENT_STEP` |
| **ORCHESTRATION** | `PlanningRunner` / `PolicyEnforcingLLMRouter` | From task + admission-bound governance identity | `task.agent_id` when present | **`principal_id`**; planner phase uses `PreModelPhase.NEXUS_PLANNING` | `task.agent_id or ""` is legacy only — not canonical |

### `evaluate_pre_llm` contract decision

**Outcome: `REVISION_REQUIRED`**

The existing `evaluate_pre_llm` / `evaluate_pre_model_policy` surface is **insufficient** for strategy-neutral PRE_MODEL:

- Add required **`principal_id: str`** (non-empty) for governance actor.
- Retain **`agent_id`** for agent-step semantics; after revision it is **optional** when `context.phase` is not `AGENT_STEP`, and **required non-empty** when `context.phase is PreModelPhase.AGENT_STEP`.
- Callers must not overload `agent_id` to carry principal identity.

GR-10-R2 implementation remediation (**GR-10-R2-R1**) is **blocked** on **GR-10-R2-C1** public contract revision unless a single combined change set explicitly merges C1+R1 under audit.

### PRE_MODEL phase

- **`phase=None`:** **valid** as generic PRE_MODEL (structured INFERENCE uses this today).
- **New `PreModelPhase.INFERENCE`:** not required for closure; may be proposed later for explicit matrix rows only.

## Execution intake boundary

### Decision: **`KEEP_REQUIRED`**

`CanonicalExecutionIntakeRequest` **officially** carries `tenant_id`, `workspace_id`, and `principal_id` as **required** public fields.

**Why Execution owns this shape:** intake is the runtime dispatch boundary **after** `RootExecutionAuthorityAdmission` proves authority. Execution must correlate dispatch with governance scope and execution identities without re-invoking admission inside the delegate.

**Source of truth:**

1. **Authority:** `RootExecutionLaunchRequest` + admission outcome (`trusted_parent_execution_authority`) — not re-derivable from payload alone.
2. **Scope projection:** `tenant_id`, `workspace_id`, `principal_id` are **copied** from the launch request at the **only** legal constructor site (`DefaultRootExecutionLauncher`). They must match values bound into `ActiveExecutionGovernanceIdentity` when `ExecutionRuntime.execute` starts.
3. **Execution IDs:** optional on intake until minted; when present must align with active execution identity binding.

**Duplicate truth rule:** launch request and intake carry the same triple **by construction** at the launcher; active governance ContextVar must match that triple for the live scope. Callers must not construct intake independently (MODEL C1 forbidden construction). Divergence is a **bug**, not a second authority.

**Breaking change:** required `workspace_id` / `principal_id` are a **documented breaking public contract change** introduced with GR-2-R3; this ADR **approves** the shape. Migration: all `CanonicalExecutionIntakeRequest` producers must supply non-empty values; direct construction outside launcher remains forbidden.

**Rejected:** `REMOVE_FROM_INTAKE` (loses stable dispatch correlation), `REPLACE_WITH_EXISTING_CONTEXT` alone (intake must remain self-describing at port boundary without service locator).

## Governance identity carrier

### Decision: **`ACTIVE_EXECUTION_GOVERNANCE_IDENTITY_ACCEPTED`**

| Attribute | Value |
|-----------|--------|
| **Type** | `ActiveExecutionGovernanceIdentity` (`tenant_id`, `workspace_id`, `principal_id`) |
| **Owner** | Execution Runtime (bind/reset lifecycle) |
| **Binding point** | `ExecutionRuntime.execute` when `RootExecutionContext` carries non-null governance scope |
| **Reset point** | Execution scope teardown (paired token reset) |
| **Nested execution** | Child scopes **inherit** tenant/workspace/principal unless a **trusted child admission** supplies a narrowed principal; blind inheritance across authority narrowing is forbidden |
| **PRE_MODEL read path** | `require_active_execution_governance_identity()` for principal/workspace; tenant must match governance identity |

**Rejected:** global service locator (`get_current_governance_identity`), Evidence-backed principal, Diagnostics-backed principal, duplicate parallel ContextVars without ownership.

### Evidence authority boundary

- **Evidence** (`failure_evidence_context`): **may** supply diagnostic `tenant_id` fallback only during transition; **MUST NOT** supply `principal_id` or workspace authority for PRE_MODEL.
- **Diagnostics / logger metadata:** **MUST NOT** be identity authority.

## Rejected alternatives

| Alternative | Why rejected |
|-------------|--------------|
| `agent_id=""` as canonical INFERENCE subject | Undefined semantics; fail-closed governance requires explicit principal |
| `agent_id="inference"` / `"default"` / `"unknown"` | Fake identity workarounds |
| Treat `agent_id` as generic `policy_subject_id` without contract rename | Hides breaking semantic change; still omits principal/workspace |
| Derive principal from Evidence / failure context | Violates Evidence non-authority |
| Derive principal from lineage alone | Lineage is scope/correlation, not principal authority |
| Global governance identity registry | Service-locator anti-pattern |
| Duplicate tenant/workspace/principal only in intake without launch/admission alignment | Duplicate truth without construction rule |
| Strategy-specific PRE_MODEL APIs (`InferenceGovernanceService`, etc.) | Violates strategy-neutral platform contract |
| Remove workspace/principal from intake | Weakens execution dispatch boundary approved under GR-2 MODEL C1 |

## Consequences

### Positive

- Clear PRE_MODEL actor model across INFERENCE / AGENTIC / ORCHESTRATION.
- Intake boundary aligned with GR-2 root launch and MODEL C1 anti-bypass gates.
- Single live governance identity carrier for PRE_MODEL + GR-8 evidence correlation.

### Negative

- Public contract change required before INFERENCE PRE_MODEL can be qualified.
- Existing `task.agent_id or ""` and `agent_id=""` paths are architecturally invalid until remediated.
- GR-10-R2 stays **BLOCKED** until C1 (+ R1).

## Qualification gates (architecture)

Semantic gates enforced in `tests/unit/runtime/architecture/test_gr10_adr1_pre_model_identity_boundary.py`:

1. **NO_EMPTY_SUBJECT (ADR):** ADR forbids empty `agent_id` as INFERENCE subject; runtime conformance gate activates after GR-10-R2-R1.
2. **NO_FAKE_INFERENCE_AGENT:** ADR rejects sentinel agent ids.
3. **ONE_IDENTITY_SOURCE:** PRE_MODEL principal must come from active governance identity, not evidence/diagnostics.
4. **NO_SERVICE_LOCATOR:** no global governance identity getter in governance core paths.
5. **STRATEGY_NEUTRAL:** contract revision is platform-wide, not Nexus/Inference-specific types.
6. **INTAKE_SHAPE_MATCHES_ADR:** required tenant/workspace/principal on `CanonicalExecutionIntakeRequest`.

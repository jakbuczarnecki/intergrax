## Context

GR-10-R9 wired a **pre-effect** meaningful side-effect (MSE) gate on `RuntimeToolInvoker` for tools with `ToolContract.side_effects=True`. Independent audit confirmed the **call-site placement** (after tool authorization, before idempotency claim / physical invoke) is valuable.

The same audit identified **architecture defects** in how orchestration production composition defines and satisfies MSE **authority**:

1. `MeaningfulSideEffectAuthorizationPort.authorize(...) -> object` — weakly typed Nexus-local port.
2. Canonical Governance authority semantics defined under `runtime/nexus/tools` instead of platform contracts.
3. Production default synthesizes `WorkspaceMembership`, `PrincipalAuthorityGrant`, permissive policy profile, and `PolicyAction.ALLOW`.
4. Production default uses concrete `InMemory*` repositories.
5. Production composition uses a fixed `datetime(2026, …)` clock.
6. Strategy matrix marked **ORCHESTRATION MSE = QUALIFIED** while graph/non-tool consequential seams remain open.

GR-10-R9-ADR1 freezes **contract ownership**, **typed surface**, **fail-closed production composition rules**, and **honest qualification** before bounded runtime remediation (**GR-10-R9-R1**).

Platform invariant: **Governance** owns permission / authorization; **Decision System** owns decision truth; **MSE** is the consequential-effect authorization boundary; **Execution** owns lifecycle; **Reliability** starts after admission; **Evidence** records facts only; **Nexus** orchestrates only.

## Problem

### Weak Nexus-owned port

`intergrax/runtime/nexus/tools/meaningful_side_effect_authorization_port.py` defines:

```python
def authorize(...) -> object:
```

Nexus must **consume** Governance authority contracts, not own them. `object` hides `permitted`, `decision`, `requires_governed_continuation`, and `governed_continuation_request`.

### Synthetic authority in production default

`orchestration_meaningful_side_effect_composition.py` (GR-10-R9) creates membership and authority grants when repositories return `None`, wires default `PolicyAction.ALLOW`, and uses in-memory stores. That violates fail-closed enterprise posture: **missing configuration must not imply permission**.

### Qualification overclaim

Tool-invoker MSE is a **qualified slice**, not full ORCHESTRATION strategy MSE closure (graph non-tool effects, universal external-work orchestration paths, control-plane mutations).

## Decision

### Alternatives considered

| Alt | Summary | Verdict |
|-----|---------|---------|
| **A** | Nexus/runtime hosts depend directly on concrete `MeaningfulSideEffectAuthorizationBoundary` only | **Rejected** — couples orchestration to runtime policy implementation; weak host pluginability |
| **B** | Promote typed public `MeaningfulSideEffectAuthorizationPort` + `MeaningfulSideEffectAuthorizationResult` under `intergrax/contracts`; runtime boundary implements port | **Accepted** |
| **C** | Single generic Governance authorization port (policy-only) without MSE continuation envelope | **Rejected** — loses `requires_governed_continuation`, enforcement provenance, decision-requirement orchestration |

Selection criterion: **architecture-correct ownership and pluginability**, not implementation ease.

### Contract ownership

| Element | Current (R9) | Approved |
|---------|--------------|----------|
| Port owner | Nexus `runtime/nexus/tools` | **`intergrax/contracts`** (Governance-facing public seam) |
| Port name | `MeaningfulSideEffectAuthorizationPort` | **Same name, relocated** |
| Runtime implementation | `MeaningfulSideEffectAuthorizationBoundary` | **Keep** in `intergrax/runtime/policy/` |
| Nexus role | Defines port | **Import port from contracts only** |

### Input contract

**Reuse:** `CollaborativeWorkEnforcementRequest` (`intergrax/contracts/collaborative_work.py`).

No Nexus-specific request model. Orchestration tool invoke projects enforcement requests via existing `tool_invocation_meaningful_side_effect` helpers.

`source_agent_id` / `source_step_id` remain optional provenance parameters on `authorize`; default `source_agent_id` for orchestration tool path must be **documented constant** in contracts or composition spec — not an undocumented magic string in Nexus-only code (**GR-10-R9-R1**).

### Output contract

**Promote to public contracts:** `MeaningfulSideEffectAuthorizationResult` (today in `runtime/policy/meaningful_side_effect_authorization.py`).

Minimum explicit fields (no dynamic attributes):

| Field | Type | Semantics |
|-------|------|-----------|
| `permitted` | `bool` | Effective authorization to proceed to physical effect |
| `decision` | `PolicyDecision` | Canonical policy outcome |
| `enforcement_result` | `CollaborativeWorkEnforcementResult` | Layered enforcement / provenance |
| `requires_governed_continuation` | `bool` | HITL / escalation path required |
| `governed_continuation_request` | `GovernedContinuationRequest \| None` | Present when continuation required |

Port signature (approved target — **implementation in GR-10-R9-R1**):

```python
def authorize(
    self,
    request: CollaborativeWorkEnforcementRequest,
    *,
    source_agent_id: str = ...,
    source_step_id: str | None = None,
) -> MeaningfulSideEffectAuthorizationResult: ...
```

**Forbidden:** `object`, `Any`, or dict-shaped authority results on the public port.

### Policy action semantics (MSE boundary)

| `PolicyAction` | Physical effect | Continuation |
|----------------|-----------------|--------------|
| **ALLOW** | Permitted after other gates | No |
| **DENY** | **Blocked** | No |
| **REQUIRE_HUMAN** | **Blocked** | Yes — existing governed continuation flow; fresh reevaluation where required |
| **ESCALATE** | **Blocked** | Yes — same continuation class as REQUIRE_HUMAN |
| **MODIFY** | **Blocked** at MSE v1 | Not supported — treat as non-ALLOW (fail closed); no silent mutation |

MSE does **not** implement decision truth; it may **invoke** `DecisionRequirementPolicy` as part of canonical enforcement (GR-6).

### Fail-closed semantics (production)

| Missing dependency | Result |
|--------------------|--------|
| Workspace membership (for required scope) | **DENY** — no synthetic membership |
| Principal authority grant | **DENY** — no synthetic grant |
| Operation policy profile | **DENY** |
| Policy evaluator / runtime policy | **DENY** — no default ALLOW |
| MSE port / boundary when effect applicable | **DENY** / composition error |
| Clock / time provider | **DENY** / composition error — no static datetime |

**Hard rules:**

- missing authority configuration → **no effect**
- platform must not invent data sufficient to ALLOW

### Production composition

**Approved enterprise posture:**

1. **`production_mode=True` orchestration tool invoker** must receive an explicit `meaningful_side_effect_authorization` port **or** fail closed at composition time.
2. **Remove** automatic wiring of `build_default_orchestration_meaningful_side_effect_authorization_boundary()` when host omits injection (**GR-10-R9-R1**).
3. Hosts (or explicit platform composition modules under `runtime/governance/`) build `MeaningfulSideEffectAuthorizationBoundary` only from **configured** repository/provider ports:

   - `WorkspaceMembershipRepository`
   - `PrincipalAuthorityRepository`
   - `AuthorityDelegationRepository`
   - `CollaborativeOperationPolicyProfileRepository`
   - `CollaborativePolicyRepository`
   - `MeaningfulSideEffectPolicyEvaluator` / runtime policy engine

4. **InMemory** implementations: tests, lab, explicit dev composition only — **not** production authority fallback.

### Clock / time dependency

**Reuse:** `TimeProvider` / `SystemTimeProvider` (`intergrax/utils/time_provider.py`).

Production MSE composition injects a **callable clock** into `CollaborativeWorkAuthorityResolver` backed by an injected `TimeProvider` (or host override). **Forbidden:** hardcoded `datetime(...)` in production Governance composition.

No new public clock contract required for GR-10-R9-R1; injection at composition boundary is sufficient.

### Pluginability model

| Concern | Mechanism |
|---------|-----------|
| Custom MSE authorization | Host provides `MeaningfulSideEffectAuthorizationPort` implementation |
| Default platform boundary | `build_meaningful_side_effect_authorization_boundary(...)` with **all** deps required |
| Nexus | `RuntimeConfig.meaningful_side_effect_authorization` optional override; no Nexus-owned contract |
| Concrete storage | Behind repository ports only |

**Forbidden:** service locator, hidden globals, static clock, synthetic authority repositories.

### Layer boundaries

| Layer | May import |
|-------|------------|
| `intergrax/contracts` | Other contracts only |
| `intergrax/runtime/policy` | contracts, collaborative_work, governance helpers |
| `intergrax/runtime/nexus` | **contracts port** — not define Governance authority API |
| Forbidden | Nexus → synthetic authority composition as production default |

### Canonical MSE flow (approved)

```text
canonical execution identity
→ inner execution binding (CanonicalInnerExecutionGuardPort)
→ tool/domain permission (ToolAccessPolicy / declarative gate)
→ canonical MSE authorization (typed port)
→ decision requirement check (DecisionRequirementPolicy when applicable)
→ idempotency / pre-effect
→ physical effect
→ reliability (post-admission)
```

### ORCHESTRATION MSE applicability model

| Effect surface | MSE applicable | Canonical boundary | Status (post-ADR1) |
|----------------|---------------:|--------------------|--------------------|
| `RuntimeToolInvoker` tools (`side_effects=True`) | Yes | Typed MSE port → boundary | **Qualified slice** (pre-effect gate wired; authority composition **not** enterprise-closed) |
| `RuntimeToolInvoker` read-only tools | No | N/A | N/A |
| External Work (host-wired) | Yes | `MeaningfulSideEffectAuthorizationBoundary` on contractor hosts | **Qualified** on proven host slices |
| Graph / non-tool orchestration mutations | TBD per path | Same boundary when consequential | **Open** — classify in GR-10-R9-R1 inventory |
| Provider mutations (generic) | Partial | Reliability + MSE where wired | **PARTIAL** |
| Control-plane mutations from orchestration | Partial | Distinct GEP / GR-12 | **PARTIAL** |

**Qualification rule:** `ORCHESTRATION MSE = QUALIFIED` only when **all applicable production consequential seams** are covered, formally N/A, or delegated to an already-qualified canonical boundary. **No qualification by representative sample.**

**Matrix impact:** `ORCHESTRATION MSE` reverts to **`PARTIAL`** until **GR-10-R9-R1** and follow-on seam closure.

### GR-10-R9 good slices (preserved)

- `RuntimeToolInvoker` pre-effect `authorize` call site for consequential tools.
- Host custom injection via `RuntimeConfig` / declarative wiring.
- Request projection to `CollaborativeWorkEnforcementRequest`.
- External Work retains existing boundary injection (unchanged by this ADR).

## Risks

- Hosts relying on permissive R9 default will **fail closed** after R9-R1 until they wire real repositories.
- Promoting result type may require careful import layering to avoid cycles.

## Rejected alternatives

- Retaining Nexus-local `-> object` port for expedience.
- Synthetic membership/authority as “bootstrap” in production.
- Default `PolicyAction.ALLOW` when policy stack unset.
- Keeping ORCHESTRATION MSE QUALIFIED on tool path alone.

## Consequences

### Positive

- Typed, auditable authority outcomes across orchestration and External Work.
- Enterprise fail-closed posture aligned with Governance Plane.
- Honest strategy matrix; clear bounded remediation.

### Negative

- R9-R1 is mandatory before GR-10-R9 closure.
- More host composition burden (intentional).

## Compliance

- Tier boundaries preserved — Nexus does not own Governance contracts.
- GR-6 / GR-7 / GR-8 relationships unchanged.
- Independent audit required before treating ADR1 as operationally closed.

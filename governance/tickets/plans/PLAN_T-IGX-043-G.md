## 2. Design rules applied to every part

1. **No NPSC path moves.** Ten modules are pinned by path in DUP-X (`tests/qualification/dup_x/test_dup_x_npsc_boundary_gates.py@H:19-32`, `..._negative_boundary.py`) and ROADMAP-REPLAY-X (`tests/qualification/roadmap_replay_x/_replay_constants.py@H:19-30`), four of them are in this ticket (`application_host_orchestration_composition`, `environment_host_task_execution`, `harness_host_internal_composition`, `host_orchestration_assembly_validation`). Moving the 8 modules into Tier-3 would also re-open EBH-2F-R1 (`WP-1/PLAN.md` section 3 S1 "Trap"). Inversion therefore keeps every file path and function name, and changes imports and signatures; two files with no pinned role are deleted (`host_orchestration_wiring_bundle.py`, `scenario_host_diagnostic_wiring.py`).
2. **Tier-3 builds neutral values by explicit field reads; Tier-1 applies them.** No pydantic round-trip projection of the mirrored profile models (that is W-B / DP-17). The neutral inputs are frozen dataclasses with named fields, so a field cannot be silently dropped by `extra="ignore"` (the S4b hazard).
3. **No dual signatures, no compatibility shims.** A changed function has one signature; callers are updated in the same commit.
4. **Fail closed where the seam carries authority.** The wiring port is `runtime_checkable` and checked before use; STRICT capacity validation stays the first statement of the Tier-3 builder (`host_orchestration_environment_spec_builder.py@H:162`).
5. **Neutral contracts import only contract modules** (EBH-2A: no `intergrax.runtime.*`, registry, bootstrap or foreign-domain implementation; `testing_support/architecture/public_contract_boundary/policy.py@H:38-54`) and carry no `# type: ignore` (EBH-2I). The sibling `host_orchestration_application_wiring_target.py` is the shape precedent, and `test_neutral_host_contract_has_no_semantic_object_or_any` forbids `object`/`Any` in `HostOrchestration*` contract classes of that file; the new files follow the same discipline.

## Problem

D5 has one real isolation hole, one real crash and four smaller real defects, all in existing code; the rest of the audit report is either wiring or feature gaps (declared exceptions below).

1. **F-D5-01 (HIGH, R015) — online evaluation observations are not tenant-isolated on any production path.** Reproduced (`probe.py`): `record_user_satisfaction` for `tenant-a` stores the row with `tenant_id=None` (`satisfaction_to_online_observation` drops `event.tenant_id`), the legacy `FileOnlineEvaluationRegistry.list_observations()` returns every row of every tenant, and the legacy `clear()` wipes every tenant's rows (`export_shadow_evaluation_trend` calls it on the default registry). `wire_application_evaluation(env, tenant_id=...)` can bind a tenant-scoped view, but `harness_host_runtime.py:542`, `runtime_config_bridge.py:197` and `scenario_runtime_baseline.py:459` call it without the tenant they hold (`tenant_id`, `request.tenant_id`, `resolved_tenant_id`); `policy_wiring.py:154` calls it too but uses only `domain_fragments` and never the registry. `record_shadow_observation` has no tenant parameter. `get_observation` returns the first row with a matching id, and `observation_id` (`shadow:{run_id}:{scenario_id}`) is not tenant-qualified, so tenant B's own row is denied when tenant A holds the same id. `runtime/adaptive/signal_emission.py` and `tools/providers/eval/service.py` read `list_observations()` through the registry protocol, so scoping the registry the hosts hold scopes every consumer.
2. **F-D5-07 (MEDIUM, real bug) — `ExperimentSession.run` is broken on every call.** `intergrax/experiments/workflow.py:163` uses `mint_run_id()` without importing it (`NameError`; since `e4079dfb1`). **Second layer, found by injecting the import in a probe (`probe_wf.py --inject`):** the run then ends `FAILED` with `[POLICY_BLOCKED]`, validation error `pre_model governance identity unavailable`, because `build_harness_root_task_execution_port_from_wiring_target(loop)` is called without `admit_root_governance_identity`, so no active governance identity is bound. `intergrax/debug/app.py` passes `admit_certified_internal_harness_root_governance_identity` for the same debug loop. With both fixes injected (`probe_wf3.py`) `tests/unit/experiments/test_experiment_workflow.py` passes (3 passed). The cited test is red today (`1 failed, 1 passed` at the first failure) and is not among the known reds.
3. **F-D5-04 (MEDIUM, R013/R010) — an evaluation can be green without evidence.** A run whose executor raised (`telemetry.error`) is recorded as `PASSED` evidence when the only rule outcome is a passing safety scan (`_run_status` looks at rule outcomes only); two empty runs compare `clean`; a pending human review (`human_pending > 0`) does not stop either (FRZ-GOV-06: missing human review is never approval).
4. **F-D5-03 (MEDIUM, R014, only the part that strengthens) — the promotion decision accepts a certification of another agent.** `evaluate_agent_promotion` never checks that `bundle.certification.agent_id/agent_version` equal `bundle.agent_id/agent_version` (reproduced by the audit, probe P8). Binding the comparison and the free-text refs to the subject is not possible without a contract change or wiring (excluded below).
5. **F-D5-02 (MEDIUM, R014, only the part that strengthens) — `check_mvp_promotion_gates.py` G0 and G2 are file-existence checks**, every symbol tuple is `()` while the docstring claims "exist and define the required symbols"; `governance_authorization` takes an `Approved:` or `Delegation:` line from anywhere in the file (`\nDelegation:` is a substring test).
6. **F-D5-11/F-D5-12 by-product (LOW).** `_CODE_SHA_PATTERN` and `_DIGEST_PATTERN` use `^...$` with `re.match`, so `"abcdef1\n"` is accepted as a code SHA (a missing-validation bug in a contract that is evidence input); the id-collision part of F-D5-12 is the same defect as item 1 (`get_observation`).
7. **F-D5-08 (MEDIUM, R017) — no document states the evaluation boundary** and the typed pipeline is documented nowhere; nothing says that it is a library without a production caller.

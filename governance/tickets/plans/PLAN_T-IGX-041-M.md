1. **The default documents loader cannot be built.** `intergrax/rag/document_loaders/handlers/doc_smart_document_handler.py:11-13` imports `PipelineDocumentHandler` from `contracts/base_document_handler.py`, which defines only `BaseDocumentHandler` (`:14`); the class is at `pipeline/document_handler_loading.py:81`. With the import redirected in memory the default loader builds in the default environment. Classified as a product defect by `tests/qualification/pdc_x/d2_repair/RAG_RED_CLASSIFICATION.md:39`.

Observed: `uv run pytest tests/unit/rag/document_loaders/parsers/test_parser_pipeline.py` fails `test_handler_attaches_native_handle_as_private_runtime_state` with `assert None is {'doc': 1}` (`get_parser_native_handle(docs[0])` returns `None`; run with `-x`: 20 tests of the file passed before it).

### P2 — G-02 (MEDIUM, regression of T-IGX-041-G, F-D7-02): the eligibility phase can end a recurrence chain

- `LongRunningScheduler._process_claimed_schedule` (`intergrax/runtime/long_running/scheduler.py:207-232`) runs the eligibility reads (`_eligible_target`, `:234-251`: `get_by_token`; `_can_materialize_checkpoint` `:385-407`, which calls `get_latest` at `:393` and the materialization gate; `_can_resume_checkpoint` `:409-416`) before `_materialize_successor` (`:214`, `:267-291`). The `get_latest` at `:217` is after the successor exists and is not affected (the auditor listed it).

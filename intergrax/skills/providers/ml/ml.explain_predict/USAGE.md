# `ml.explain_predict`

**Bundle:** `ml` · **Version:** 1.0.0 · **Risk:** `medium`

## Purpose

ML inference with explainability: predict, explain, and batch predict.

## How it works

Resolves registered `tool_id`s at agent bind time via `SkillResolver`; tools execute through `ToolRuntime` under host policy.

## How to use

Use `ml_skill_profile()`; Enable bundle `ml` on `SkillProfile` or list this manifest on `AgentContract.skills`.

## What you get

Governed access to: `ml.predict`, `ml.explain`, `ml.batch_predict`.

## Tools unlocked

| `tool_id` | Role |
|-----------|------|
| `ml.predict` | Catalog tool |
| `ml.explain` | Catalog tool |
| `ml.batch_predict` | Catalog tool |

# Intergrax harness demo project

Minimal external layout generated by `intergrax init demo`.

1. Install Intergrax (`pip install` from your distribution or editable monorepo).
2. Run `python app.py` or `intergrax run app:app`.
3. `curl -X POST http://127.0.0.1:8091/v1/demo/run -H 'Content-Type: application/json' -d '{"message":"hi","capability":"echo.basic"}'`

Replace `EchoAgent` with your own `IntergraxAgent` subclass under `agents/`.
